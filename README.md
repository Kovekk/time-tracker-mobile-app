# Overview

This app is meant to help track time spent on a task or project. To use the app
you type in the project your working on and a short description of what you will be doing.
Then you tap the clock in button and the app will display what time you clocked in at.
Once you are finished you tap the clock out button and it will display how long you spent
working.

I created this app for two reasons, first to learn how to create android app GUIs. Second,
I wanted to create this app to help me track time I spend on future projects.
